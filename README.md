# aeroshield-ai-predictive-maintenance-
**AeroShield AI – Predictive Maintenance for Aircraft Engines**

AeroShield AI is an aircraft engine predictive maintenance project that uses machine learning and Palantir Foundry to analyze engine sensor data and support proactive maintenance decisions.

The project uses NASA's CMAPSS dataset, data preprocessing, XGBoost and Bi-LSTM models for Remaining Useful Life (RUL) prediction, and SHAP for model explainability. In Phase 3, Palantir Foundry was used to build an Engine Summary Pipeline, create Engine and Sensor Reading ontology objects, establish relationships between them, and develop Contour visualizations. An additional engine-level risk classification identifies High Risk and Low Risk engines using summary metrics.

**Key Features**
- Aircraft engine sensor data processing and cleaning
- XGBoost and Bi-LSTM-based RUL prediction
- SHAP-based model explainability
- Palantir Foundry pipelines and Ontology
- Contour visualizations for engine-level analysis
- Engine-level risk classification for maintenance prioritization

**Future Scope:** Integrate RUL model predictions directly into Foundry, enable real-time engine health monitoring, and develop AI-assisted maintenance recommendations.
